# 信息筛选、来源核查与推荐方法

本文说明《AI 智能体安全与隐私行业观察》的公开信息调研方法。报告持续关注行业动态与安全事件、产品与产业安全实践，以及学术与技术研究。

## 检索与覆盖

调研分别覆盖个人助理与长期记忆、手机智能体与跨应用执行、办公智能体与工具调用、车载助手与设备协同等场景，并兼顾国内外信息。

检索阶段先保证主要方向得到实际覆盖，再依据材料价值决定是否写入正文。某一方向没有合适新增材料时，不以低相关内容填充，也不把条目较少等同于已经充分检索。

## 内容筛选

材料取舍综合考虑以下因素：

- 与智能体安全及隐私问题的相关性；
- 是否提供新的事件、机制、证据或技术进展；
- 对产品实践、安全评估或研究工作的参考价值；
- 来源质量、事实可核查性和结论边界。

有明确变化且值得读者了解的材料进入正文；对当前研究或评估工作有直接参考价值的材料推荐精读；能够补充认识但无需深入展开的材料作为参考；发布状态、效果或关键结论尚不明确的材料列为持续观察。

## 来源与状态核查

优先使用官方公告、原始事件披露、论文原文、会议资料、研究报告和项目仓库。媒体报道和用户反馈可以作为事件线索或补充材料，但不替代能够取得的原始来源。

对重要内容重点核查：

- 事件发生时间与报道时间是否一致；
- 论文是预印本、已录用还是正式发表；
- 主会、Findings 和 Workshop 等发表状态是否准确；
- 结论来自作者或企业主张、第三方观察，还是报告自身判断；
- 公开结果是否存在测试环境、样本范围或独立验证方面的限制。

无法确认的信息不补写为事实。影响判断的限制放在相应条目中说明。

## 连续跟踪与去重

每期调研读取既有报告、事件与文献索引以及持续关注事项。已经收录的材料只有在出现实质性新版本、新证据、修复、验证结果或结论变化时才再次跟进，并说明本次新增内容。

趋势判断需要跨期材料支持。单个事件或少量论文可以形成具体发现，但不据此直接推断整个行业趋势。

## 报告呈现

完整报告通常包括本期重要发现、行业动态与安全事件、产品与产业安全实践、学术与技术研究，以及用于回溯的索引和持续关注事项。

概要在完整报告完成后生成，保留重要条目的覆盖面并逐条凝练。每项概要都应能够在正文中找到依据，不增加未经核查的事实或判断。Markdown 是内容底稿，概要和 PDF 与对应期次的 Markdown 保持一致。
